# Integración TAME-Quíntuple · Módulo 1

## Propósito

Esta carpeta amplía las clases didácticas del Módulo 1 con una capa formal para analizar la Regulación Bioeléctrica y el punto trauma mediante TAME.

## Convenciones

- $S$: estados alcanzables y observables.
- $O$: operadores o acciones disponibles.
- $C$: restricciones que cierran rutas.
- $E$: estado o relación que el sistema defiende.
- $H$: profundidad temporal de anticipación y retardos físicos.
- $w$: costo, eficiencia o pérdida de ganancia de un operador.
- $\Lambda$: alcance espacial del agente.
- $\Phi_{flex}$: flexibilidad de trayectorias.
- $\Sigma_{int}$: integración o superaditividad entre escalas.

## Principio de uso

La integración no presenta TAME como una confirmación automática del método. Cada sección añade una interpretación, una medición requerida y una condición de refutación.

## Límite clínico

Estos documentos son material docente y de investigación. No sustituyen diagnóstico, consentimiento informado, supervisión clínica ni tratamiento médico. El rastreo se trata como proxy hasta que su fiabilidad y validez convergente sean demostradas.
