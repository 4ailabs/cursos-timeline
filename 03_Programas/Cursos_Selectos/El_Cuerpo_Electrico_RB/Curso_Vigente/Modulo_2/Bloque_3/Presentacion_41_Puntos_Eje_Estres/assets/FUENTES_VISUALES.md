# Criterio de precisión visual

Las antiguas láminas de cabeza y cuello con múltiples marcadores se retiraron de la presentación: mezclaban varias localizaciones en una misma imagen y podían sugerir una precisión que el material no justificaba. El deck activo usa un solo acercamiento y un solo marcador por diapositiva. Para el periné y la planta del pie se crearon esquemas originales específicos sin marcadores secundarios.

## Láminas clínicas generadas para esta presentación

- `atlas-cabeza-cuello.png`: cabeza y cuello, vistas anterior, lateral y posterior.
- `atlas-tronco-pelvis.png`: tronco y pelvis, vistas anterior y posterior.
- `atlas-miembro-superior.png`: cintura escapular y miembros superiores, vistas anterior y posterior.
- `atlas-miembro-inferior.png`: rodillas, piernas, tobillos y pies en vistas anterior, posterior y plantar.

Estas cuatro bases fueron generadas con el sistema visual de OpenAI para uso científico-educativo, sin texto ni marcadores incrustados. La presentación superpone de forma independiente la geometría docente: diana para referencias puntuales, elipse para regiones y banda para trayectos. No deben utilizarse como sustituto de un atlas anatómico clínico ni para diagnóstico.
