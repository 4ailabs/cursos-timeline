# Atlas docente · 41 puntos del eje del estrés

Presentación HTML 16:9 con una diapositiva por cada entrada del mapa consolidado de 2026.

## Uso

- Abrir `index.html`.
- Flechas o clic para navegar.
- Barra espaciadora para revelar referencias, relaciones y precisiones.
- `N` abre las notas docentes.
- `F` activa pantalla completa.

## Criterio editorial

La presentación separa la ubicación anatómica verificable de la instrucción operativa del método.
Los marcadores visuales son orientativos y señalan regiones de exploración; no representan puntos
milimétricos ni proyecciones exactas de órganos.
