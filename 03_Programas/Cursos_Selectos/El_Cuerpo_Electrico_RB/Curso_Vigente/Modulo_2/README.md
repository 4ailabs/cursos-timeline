## Reglas

- Terminología única: **microambiente tisular**, Vmem primario, nodo, dipolo, eje/terreno.
- **Programa de defensa** = el proceso (inicio · ejecución · resolución). **Tono de defensa** = la variable regulable, en tres escalas: muscular, autonómica e inflamatoria. **No se usa "mecanismos de defensa"** — pertenece a otra tradición.
- Maniobras en **rúbrica completa** — polo, cara, comprobación, tiempo y criterio de retirada. No se abrevian.
- Sin fuente, se declara. Donde no hay nodo bioeléctrico literal, se dice.
