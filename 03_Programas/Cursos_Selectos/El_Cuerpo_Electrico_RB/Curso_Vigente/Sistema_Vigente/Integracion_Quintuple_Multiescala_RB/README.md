## Decisión resumida

El quíntuple **no es un quinto nivel**. Es la gramática formal que atraviesa los cuatro niveles vigentes. El terreno es contexto; el agente se instancia; la agencia se demuestra perturbando; y el rastreo se conserva como instrumento en validación, no como prueba autosuficiente del mecanismo.
