# Sistema_Vigente — Workspace del sistema nuevo de RB

> **Léeme primero.** Esta carpeta contiene el **sistema nuevo** de Regulación Bioeléctrica: el que organiza la clínica por **agentes biológicos** y **terrenos**, para el rediseño del curso *El Cuerpo Eléctrico* (generación 2026). Todo lo de aquí es **vigente**. Si trabajas en el curso, este es tu punto de partida.

---

## Qué es "el sistema nuevo" (en una frase)

El cuerpo es un sistema eléctrico; cada órgano es un **agente** que persigue una meta y defiende un **set point** con sustrato bioeléctrico. En vez de rastrear el cuerpo punto por punto (sistema anterior), se **razona por agente** y se trabaja por **terrenos** — sirve tanto para tratar como para mantener la salud (salutogénesis).

## El modelo, en corto (para no confundirse)

**Marco de 4 niveles (por agente):** circuito → cibernética/clase B → agencia/bioelectricidad → inferencia activa.

**Estructura de mantenimiento:** 1 eje transversal + 5 terrenos.
- **Eje:** carga alostática / alerta sostenida (SNA + HPA) — se atiende primero.
- **Terreno 1:** Inflamatorio no-resolutivo (inmune)
- **Terreno 2:** Metabólico-energético (mitocondria + insulina)
- **Terreno 3:** Biotransformación / exposoma (hígado)
- **Terreno 4:** Redox-envejecimiento (fondo)
- **Terreno 5:** Barrera / disbiótico (intestino)

## Reglas de trabajo (para IA y para el equipo)

- **No inventar contenido.** Si no hay fuente para un dato/nodo, se dice. Donde no hay nodo bioeléctrico literal (ej. hígado), se declara — no se inventa.
- **No usar el marco viejo.** No describir esto como "el par biomagnético evolucionado". Es un sistema distinto (agentes + terrenos).
- **El Tratado (`../../Fundamentos_Cientificos/Regulacion-bioelectrica/`) es base de evidencia científica, no el método clínico.** Se cita su ciencia (Vmem, MEC, campos magnéticos, terreno), pero su método punto-por-punto está superado por el razonamiento por agente.
