# Cómo se describe un sistema que se regula solo

Presentación HTML de 11 diapositivas para el Módulo 3, Bloque 1. Construida a partir de `GUION_Bloque_1.md` sin modificar el archivo original.

## Abrir

- `index.html`: presentación animada.
- `guion-tarjetas.html`: guion docente completo con búsqueda, vista compacta e impresión.

## Controles del deck

- Flechas, espacio o clic: navegar y revelar elementos.
- `N`: abrir o cerrar las notas completas del presentador.
- `F`: pantalla completa.
- `Inicio` / `Fin`: primera o última diapositiva.

Las notas del panel y las tarjetas utilizan `class-notes.js`, por lo que permanecen sincronizadas.

## Figuras científicas

La presentación incluye cuatro figuras conceptuales originales, generadas para esta clase y rotuladas en HTML:

- sistema de control con referencia alineada o desplazada;
- hígado estructuralmente preservado y cambio de valor defendido;
- tejido coordinado frente a una isla despolarizada con uniones gap cerradas;
- aumento de fuerza frente a apertura de una restricción mediante gradiente.

Estas imágenes son recursos didácticos conceptuales, no resultados experimentales ni evidencia primaria.
