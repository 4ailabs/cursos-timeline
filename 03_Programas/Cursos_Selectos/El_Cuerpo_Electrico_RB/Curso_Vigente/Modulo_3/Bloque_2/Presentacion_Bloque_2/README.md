# Presentación · Bloque 2 · Eje digestivo

Presentación HTML de 31 láminas construida a partir de `GUION_Bloque_2.md`, sin modificar el archivo fuente.

## Abrir

- `index.html`: presentación animada.
- `guion-tarjetas.html`: notas docentes en 31 tarjetas con búsqueda e impresión.

## Controles

- Flechas, espacio o clic: avanzar, retroceder y revelar elementos.
- `N`: notas del presentador.
- `F`: pantalla completa.
- `Inicio` / `Fin`: primera o última lámina.

## Sistema visual

El deck reutiliza el lenguaje editorial de la clase del quíntuple: marfil y azul profundo, tipografía serif de alto contraste, azul para coordinación, ámbar para gradientes y óxido para pérdida o rigidez. Incluye ocho figuras científicas originales y veintitrés diagramas SVG animados.

Las figuras son explicaciones conceptuales, no resultados experimentales. Las fuentes y cautelas del guion aparecen en las notas de cada lámina.

## Revisión editorial

El archivo `editorial-revision.js` aplica una versión terminológica más directa a la presentación y a las tarjetas. Distingue entre observación, medición e interpretación del modelo; define C, E, H, trinquete y permiso contextual; y reemplaza metáforas por descripciones causales.
