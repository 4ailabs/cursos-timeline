El quíntuple:
fórmulas sin miedo

Una gramática visual para describir qué puede hacer un sistema, qué persigue y por qué se atasca.

IDEA DE SALIDAPodrás mirar una fórmula y convertirla en cinco preguntas concretas, sin “hacer matemáticas”.

Apertura

Pregunta al grupo: “¿Una fórmula puede ser útil aunque no la calcules?”. Explica que hoy las fórmulas serán mapas comprimidos: cada símbolo obliga a hacer una pregunta.

Fuente interna: README; Curso quíntuple, módulo 1.

Antes de empezar

Contrato didáctico

No pedir operaciones algebraicas. Cada ecuación se leerá de izquierda a derecha y se traducirá inmediatamente.

La ciudad como laboratorio

Un taxi no es solo un coche.

También necesita un mapa, caminos abiertos, destino e información del futuro.

PREGUNTASi el taxi no llega, ¿falla el motor, está cerrada una calle, tiene mal el destino o vio tarde el tráfico?

Escena base

Mantén esta ciudad como ejemplo continuo. La misma falla observable —“no llegó”— puede provenir de letras distintas, y por tanto pedir intervenciones distintas.

Mapa de preguntas

Haz que el público lea las cinco preguntas en voz alta. Es el único bloque que sí conviene recordar.

S · estados

Todo lugar donde el sistema podría estar.

🚕

Ahora: Roma Norte. Meta: aeropuerto. Posibles: todas las esquinas alcanzables.

S = {s₁, s₂, s₃, …}
el catálogo de situaciones posibles
NO CONFUNDIRS dice dónde está o puede estar. No dice todavía qué estado considera deseable.

S

En metabolismo, un estado es una configuración conjunta: glucosa, insulina, glucagón, reservas, tono nervioso, etc. No es una sola variable.

O · operadores

Las acciones que cambian un estado.

Girar, frenar, avanzar. En el cuerpo: secretar, captar, movilizar.

o: S → S
una acción lleva de un estado a otro
w(o) ≥ 0
cada acción tiene un costo
IDEA CLAVEPoder hacer algo no significa que sea gratis: el costo puede ser tiempo, energía, desgaste o riesgo.

O y w

Avanza una vez para revelar w. La notación o:S→S se entiende como una flecha, no como cálculo. w es una función que asigna costo a cada acción.

Fuente interna: capa1-dominio-v2 §1.1; módulo 1.

C · restricciones

Las combinaciones prohibidas.

No toda acción puede hacerse en todo estado.

SE LEEC contiene los pares “estado + acción” que el sistema no puede ejecutar.

C

Formalmente C es una relación dentro de S×O. Para público general: una calle puede estar abierta para un taxi y cerrada para un camión; la restricción pertenece a la combinación situación-acción.

Lo permitido se obtiene por descarte

A = (S × O) \ C
todas las combinaciones menos las prohibidas
POR QUÉ IMPORTAAbrir una restricción no añade una acción: puede crear muchas rutas nuevas de golpe.

Conjunto admisible A

“×” aquí significa combinar cada situación con cada acción. “\” significa quitar. La consecuencia pedagógica es más importante que la notación: C cambia la geometría completa del problema.

Fuente interna: capa1-dominio-v2 §1.1; módulo 1.

Una restricción no es necesariamente una falla

C también organiza y protege.

Una puerta sana se cierra cuando corresponde y vuelve a abrirse cuando cambia el contexto.

PREGUNTA CLAVE¿La restricción está mal, o era correcta y quedó aplicada en el momento equivocado?

Restricción funcional

Una restricción funcional es reversible al cambiar el contexto. El modo de fallo aparece cuando un cierre apropiado se vuelve permanente. C no es un obstáculo añadido a la regulación: participa en la regulación.

Fuente interna: marco-tame-base-conocimiento-v3 §3.3–3.4.

C puede fallar en dos direcciones

Demasiada restricción atrapa. Muy poca desorganiza.

δC+

Rigidificación

Se cierran caminos que deberían estar abiertos. El sistema queda atrapado.

δC−

Debilitamiento

Se pierden límites que deberían existir. El sistema pierde contexto y organización.

NO CONFUNDIREn un caso hay que abrir un camino; en el otro hay que restaurar una restricción. La intervención se invierte.

Dos patologías de C

Usa una avenida bloqueada para δC+ y un cruce sin semáforos ni carriles para δC−. Ambas son alteraciones de C con signo opuesto.

Fuente interna: marco-tame-base-conocimiento-v3 §3.5.

E · evaluación

El criterio interno de “voy bien”.

Un sistema puede actuar con enorme competencia hacia una meta equivocada.

E: S → ℝ
cada estado recibe una valoración
📍

GPS mal tecleado: conduce perfecto, llega al lugar equivocado.

PRUEBASi al apartarlo regresa activamente al mismo valor, ese valor pertenece a E, no solo a S.

E

ℝ quiere decir que E asigna una puntuación. En sistemas predictivos puede ser una distribución esperada, no un único punto. Usa “destino interno” como andamio y aclara que el término técnico del repositorio es prior.

H · horizonte

Cuántos pasos puede anticipar.

No es fuerza de voluntad: depende de qué información llega y con cuánto retraso.

SE LEEH grande prepara antes de que ocurra el desvío; H pequeño solo reacciona cuando el problema ya llegó.

H

El repositorio lo define como profundidad de anticipación derivada de líneas físicas de retardo. Evita psicologizarlo.

Primera síntesis

Cinco fallas distintas pueden producir el mismo resultado: “no llegó”.

S · el destino no es alcanzable

No existe una configuración posible que cuente como llegada.

O · falla el motor

Falta una acción necesaria.

C · el camino está cerrado

La acción existe, pero no está permitida aquí.

E o H · destino/anticipación

Persigue otro lugar o descubre demasiado tarde el obstáculo.

DIAGNÓSTICOEl síntoma no identifica la letra. La intervención correcta depende de distinguirlas.

Síntesis diagnóstica

Pide al grupo una intervención para cada cuadrante: construir acceso, reparar motor, abrir calle, corregir GPS o restaurar información anticipatoria.

La distinción que cambia todo

¿Faltan piezas o falta organización?

Maquinaria

S + O

Estados realizables y acciones disponibles. Se repara o se repone.

Información

C + E + H

Permisos, criterio y anticipación. Se reescribe o se reconecta.

K · eficiencia de búsqueda

¿Cuánto mejor que el azar?

Compara al taxista con un caminante que elige al azar.

K = log₁₀(τciego / τagente)
cuántos ceros de ventaja obtiene el agente
τSe pronuncia “tau” y aquí significa tiempo promedio para llegar.

K

τ_ciego y τ_agente deben vivir en la misma ciudad, con las mismas restricciones y costos. Explica logaritmo como contador de ceros.

Fuente interna: capa1-dominio-v2 §1.3a; módulo 2.

Cómo leer K

El documento operativo v2 corrigió una interpretación previa: K mide eficiencia, no agencia. Enfatízalo antes de mostrar Φflex.

El caso que vuelve visible la escala

Una planaria encuentra una solución que el azar no podría recorrer.

Ante bario, regenera una cabeza capaz de funcionar en ese entorno en 37 días.

LO QUE SE MIDENo “si piensa”, sino cuánto tiempo ahorra frente a una búsqueda sin dirección.

Historia de la planaria

Cuenta la secuencia completa del módulo: el bario compromete la cabeza; el animal regenera una cabeza funcional en el nuevo entorno. El ejemplo se usa para estimar eficiencia de búsqueda, no para probar conciencia.

Fuente interna: Curso quíntuple, módulo 2; calibración resumida en marco-tame-base-conocimiento-v3 §4.1.

Por qué el resultado es K ≈ 21

K = log₁₀(10²⁰ años / 37 días)
aproximadamente 21 ceros de ventaja

La búsqueda ciega tardaría cerca de 10²⁰ años bajo los supuestos del modelo; el agente tarda poco más de un mes.

CALIBRACIÓNQuimiotaxis unicelular ≈ 2.2 · adaptación de planaria ≈ 21. Si K sale fuera de 0–25, revisa primero el modelo nulo.

Cálculo intuitivo

37 días son cerca de una décima de año. Dividir 10²⁰ años por 10⁻¹ años produce una razón cercana a 10²¹; log10 convierte esa razón en 21.

Recuerda la cautela: el número depende del espacio de búsqueda, paralelismo y ritmo de prueba asumidos.

Fuente interna: Curso quíntuple, módulo 2; capa1-dominio-v2 §3.2.

La trampa del borracho

K vale lo que valga tu comparación.

Si haces al azar artificialmente torpe, cualquier agente parece brillante.

CONTROLEl agente y el azar deben enfrentar el mismo espacio, restricciones y costos.

Cautela con K

Esta limitación es una fortaleza metodológica: obliga a declarar los supuestos. El repositorio exige no reportar K absoluto como propiedad intrínseca.

Φflex · flexibilidad de medios

¿Puede cambiar de ruta sin cambiar la meta?

Φflex = ℋ(π | llegada) / log|Πadmisibles|
diversidad de rutas exitosas, ajustada por cuántas eran posibles
TESTBloquea la ruta favorita: si encuentra otra, hay flexibilidad; si colapsa, había eficiencia rígida.

Φflex

Haz un clic para bloquear la ruta central. ℋ significa diversidad o entropía; Π, el conjunto de rutas admisibles. Φflex operacionaliza “fines fijos con medios variables”.

Fuente interna: capa1-dominio-v2 §1.3b; capa2-metodos-v2 §3.6.

No son lo mismo

Llegar rápido y tener alternativas son capacidades distintas.

K alto · Φ alto

Llega rápido y se adapta cuando cierran una vía.

K alto · Φ bajo

Llega rápido, pero solo por una ruta. Es eficiente y frágil.

K bajo · Φ alto

Prueba muchas rutas, pero todavía con poca eficiencia.

K bajo · Φ bajo

Ni eficiencia ni alternativas suficientes.

TESIS CONTRASTABLEEl marco propone que Φflex puede caer antes y más que K: el sistema se rigidiza antes de volverse ineficiente.

Matriz K-Φ

Pregunta cuál cuadrante parece sano. La respuesta depende del entorno, pero el cuadrante superior derecho combina eficiencia y flexibilidad. Marca la tesis como predicción del marco.

Σint · integración entre partes

¿El conjunto ahorra más búsqueda que sus piezas?

Coordinar puede producir un rendimiento que no aparece al sumar individuos aislados.

Σint = Ktotal − Σ Kj
ventaja del conjunto menos la suma de ventajas individuales
CAUTELAEl repositorio exige normalizar esta métrica; además, identificarla con “sinergia informacional” sigue siendo una hipótesis.

Σint

La primera Σ es el nombre de la métrica; la segunda es la instrucción “suma todas las K individuales”. La presentación conserva la fórmula intuitiva; el análisis debe reportar su forma normalizada.

Fuente interna: capa1-dominio-v2 §1.3d.

IDI · divergencia interpretativa

Dos formas de dejar de coordinar.

No compartir información y responder en direcciones opuestas no son la misma falla.

Dacop

¿Las partes dejaron de informarse?

Dcoh

¿Reciben información, pero responden con signo opuesto?

REGLAIDI se reporta como dos números, nunca como una sola puntuación que esconda la diferencia.

IDI bicomponente

La versión anterior era ciega a respuestas perfectamente opuestas. El documento corregido separa pérdida de acoplamiento y pérdida de coherencia direccional.

Fuente interna: capa1-dominio-v2 §1.3e; capa2-metodos-v2 §3.7.

Λ · alcance de preocupación

¿Hasta qué escala provoca una respuesta?

Λ = escala máxima con acción correctiva
hasta dónde “le importa” el desvío
MEDICIÓNPerturba escalas sucesivas y registra la más alta que todavía provoca corrección.

Λ

Se pronuncia lambda. La perturbación debe ser equipotente entre escalas; de otro modo Λ mediría fuerza del estímulo, no alcance.

Fuente interna: capa1-dominio-v2 §1.3c; capa2-metodos-v2 §3.7.

La geometría del agente

Cono cognitivo = Λ × H
escala que abarca por futuro que anticipa

Amplio no significa “mejor” en todo contexto. Significa que responde a más distancia espacial y temporal.

CONTRACCIÓNUn agente puede seguir siendo eficiente dentro de un problema que se volvió más pequeño.

Cono cognitivo

La multiplicación es conceptual: dos dimensiones. Esta adaptación sigue la definición espaciotemporal del repositorio y la geometría del cono de Michael Levin usada en la primera presentación.

η · eficiencia de control

¿Cuánto hizo el sistema por sí mismo?

Una señal pequeña con recuperación grande sugiere que encontramos un buen nivel de intervención.

η = Δ(capacidad recuperada) / Iintervención
resultado propio por cada unidad de información externa
η ALTONo significa magia ni prueba una terapia: indica que el sistema aportó la mayor parte del trabajo.

η

Se pronuncia eta. Δ indica cambio recuperado; I, información introducida. Usa el ejemplo de abrir una compuerta frente a bombear agua continuamente. Mantén el estatuto: criterio de apalancamiento, no recomendación clínica.

Fuente interna: capa1-dominio-v2 §1.3f; módulo 7.

El bucle que cambia el problema

S → C

El estado alcanzado puede reescribir las restricciones futuras.

DE CASCADA A ATRACTORLo ocurrido ayer puede cerrar caminos mañana y hacer que el sistema vuelva al mismo estado.

S→C

Esta es una de las extensiones centrales: el sistema no solo navega el problema, también puede reescribirlo. Si las restricciones persisten, aparece memoria estructural.

Cómo nace un trinquete

Una respuesta útil hoy puede estrechar las opciones de mañana.

TRINQUETEEl sistema puede avanzar hacia el estado problemático con cada episodio, pero no regresar con la misma facilidad.

Secuencia del trinquete

El primer estado ya aparece; revela las otras cuatro etapas por clic. No toda compensación deja marca: hay trinquete cuando la marca persiste y modifica C, reduciendo la reversibilidad del siguiente episodio.

Busca tres propiedades: convergencia sobre pocas dianas, autotoxicidad de la respuesta y acumulación de irreversibilidad.

Fuente interna: marco-tame-base-conocimiento-v3 §5; Curso quíntuple, módulo 9.

Nueve maneras de reescribir C

No todos los cierres tienen la misma reversibilidad.

Bucles, identidad y organización

Comprobación

Una última traducción

La fórmula no reemplaza la historia.

La obliga a ser precisa, comparable y refutable.
