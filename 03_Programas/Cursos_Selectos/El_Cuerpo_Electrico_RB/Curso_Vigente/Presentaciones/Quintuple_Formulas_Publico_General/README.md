# El quíntuple: fórmulas sin miedo

Segunda presentación HTML de 41 diapositivas para enseñar el quíntuple y sus fórmulas principales a público no experto. Incluye bloques desarrollados sobre restricciones, el cálculo de `K` con la planaria y la formación/tipología de trinquetes.

## Abrir

Abrir `index.html` en un navegador moderno. Funciona mediante `file://` y no requiere servidor.

Abrir `guion-tarjetas.html` para consultar las 41 tarjetas de conducción con guion hablado, interacción, capa experta, transición y fuentes. Incluye búsqueda, vista compacta e impresión.

## Controles

- Flechas, espacio o clic derecho: avanzar y revelar fragmentos.
- Flecha izquierda o clic izquierdo: retroceder.
- `N`: notas del presentador.
- `F`: pantalla completa.
- `Inicio` / `Fin`: primera / última diapositiva.

Las notas ampliadas del panel `N` y las tarjetas utilizan el mismo archivo `class-notes.js`, por lo que permanecen sincronizadas con el deck.

## Alcance y fuentes

La secuencia se construyó a partir de `README.md`, `marco-tame-base-conocimiento-v3.md`, `capa1-dominio-v2.md`, `capa2-metodos-v2.md` y los módulos 1, 2, 7 y 9 de `Curso quintuple/` del repositorio local `quintuple-multiescala`.

Las fórmulas se presentan en capas: traducción cotidiana, notación compacta y cautela de interpretación. Las aplicaciones biomédicas se presentan con el estatuto del repositorio: trabajo en desarrollo, no medicina establecida ni recomendación clínica.
