# Clases impartidas — registro

Esta carpeta guarda el registro de las sesiones **tal como se dieron**, reconstruido desde la transcripción del audio.

## Regla

**Nada de lo que hay aquí se edita, y los guiones de las sesiones ya impartidas tampoco.** Una vez dada la clase, el guion queda como el registro de lo que se preparó, y el documento de esta carpeta como el registro de lo que ocurrió. La diferencia entre ambos es información, no un error que corregir.

Lo que estos registros aportan se recoge solo en las sesiones que todavía no se dan.

## Qué contiene cada registro

1. La estructura real de la clase con tiempos.
2. Los conceptos que se enseñaron en vivo y no existen por escrito.
3. Lo que el guion tenía y no se dio, con la consecuencia práctica de cada hueco.
4. Los compromisos hechos con el grupo.
5. Los puntos a resolver antes de la siguiente sesión.
6. Las frases y ejemplos que funcionaron, para reutilizar.
7. Qué se arrastra hacia las sesiones pendientes.
