# Cómo se escribe en este repositorio

Material clínico y docente del Instituto Centrobioenergetica. **Se escribe como escribe un
clínico: descriptivo, sin ambigüedad, sin frases que anuncian.**

Estas cuatro reglas se aplican al escribir, no al revisar. Antes de entregar cualquier archivo,
correr:

```bash
python3 _Herramientas/revisa_registro.py <ruta> --nuevos
```

---

## 1 · La frase dice el hallazgo. No lo anuncia

El defecto más frecuente, y el que produce el tono que el Dr. rechaza.

| Nunca | Se escribe |
|---|---|
| **Y la respuesta tiene un dato que la sostiene:** en los plexos hay… | En los plexos de la pared del tubo digestivo hay… |
| **Y el dato que lo cierra:** | *(se dice el dato)* |
| **Y aquí está lo más aprovechable:** | *(se dice)* |
| **Dos cosas que hay que decir:** | *(se dicen las dos)* |
| **Se abre con el ejemplo, no con el concepto:** | El tramo abre con un caso: |

**Un documento clínico afirma. No presenta lo que va a afirmar.**

---

## 2 · El encabezado se escribe al final, desde lo que la sección dice

Escrito antes, solo puede nombrar el papel del texto. **Un encabezado es una afirmación
comprobable, no una etiqueta.**

| Nunca | Se escribe |
|---|---|
| Lo que el bloque instala | Qué tiene que poder hacer el alumno al salir |
| La ficha | La hoja de consulta que se entrega |
| Qué se registra | Qué se anota, y de qué |
| El tubo y cómo se explora | Las once unidades del tubo digestivo, y cómo se rastrea cada una |

---

## 3 · El nombre completo cada vez, aunque se repita

**Nunca se acuña un apodo corto para algo que ya tiene nombre.** El apodo solo significa algo para
quien vio cómo se construyó.

| Nunca | Se escribe |
|---|---|
| el barrido | el complejo motor migratorio |
| el sello | la unión estrecha |
| el compás | la frecuencia de las ondas eléctricas |
| la comunidad | la microbiota |
| el tubo | el tubo digestivo |
| la firma, la ventana, el calibre | *(nombrar la cosa)* |

**Y cada verbo dice qué ocurre físicamente:** «rinde más» → «produce más cambio»; «no arranca» →
«no se inicia, y nombrar qué célula no hace qué».

---

## 4 · El documento nunca habla del documento

| Nunca | Se escribe |
|---|---|
| Qué hace este documento | *(se elimina, o se dice el contenido)* |
| Lo que se hace aquí | *(se hace)* |
| Y de ahí sale | *(se afirma lo que sale)* |
| Esto es la integración | *(se integra)* |

---

## Reglas de registro que ya estaban

- **Nunca lenguaje de contacto.** En Regulación Bioeléctrica no se toca al paciente: se **coloca**,
  se **rastrea**, se **mide**, se **interviene**.
- **Nunca «no es X, es Y».** Se afirma directo.
- **Nunca «levantar»** aplicado a un documento. Un mapa se **registra**, se **marca**, se **traza**.
- **Prohibidas:** honesto/honestidad, roto, avería, guardarraíl.
- **Español mexicano.** Nada de calcos de España.
- **No inventar.** Si no hay fuente, se dice que no la hay. El Dr. puede pedir «fuente» y hay que
  poder mostrarla.
- **Estatuto epistémico por afirmación** en material técnico: `[EVIDENCIA]` · `[DERIVADO]` ·
  `[INTERPRETACIÓN]` · `[HIPÓTESIS]` · `[ESPECULACIÓN]`.

---

## Después de cada corrección

Se pega el **texto completo resultante**, limpio y de corrido. Nunca solo el fragmento cambiado.
